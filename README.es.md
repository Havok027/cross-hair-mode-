# 🎯 Plugin Crosshair

Una mira personalizable para Decky Loader, diseñada para Steam Deck, Legion Go y otros PC portátiles.

**Idioma:** [Português](README.md) · [English](README.en.md) · **Español**

## Funciones
- Siete estilos: caja, punto, anillo, X, estrella, corchetes y líneas.
- Colores predefinidos y RGB personalizado; tamaño del 50 % al 300 %.
- Resoluciones predefinidas y ajuste fino de posición X/Y.
- Atajo de dos botones del mando para activar o desactivar la mira.
- Perfiles por juego, aplicados automáticamente al iniciar un juego.
- Restaura la configuración anterior de MangoHud al desactivar la mira.

## Instalación
1. Descarga la [última versión de Crosshair](https://github.com/Havok027/crosshair-plugin/releases/latest).
2. Activa el modo desarrollador en los ajustes de Decky Loader.
3. Selecciona **Instalar plugin desde ZIP** y elige `Crosshair.zip`.
4. Reinicia Decky si el plugin no aparece.

## Uso
1. Abre Crosshair desde el menú de Decky.
2. Elige la resolución, el estilo, el color y el tamaño.
3. Activa **Mostrar mira**.
4. Ajusta los desplazamientos horizontal y vertical si es necesario.
5. Opcionalmente, guarda un perfil para el juego en ejecución.

## Atajo del mando
1. Abre la sección **Atajo de botones**.
2. Selecciona **Grabar combinación**.
3. Pulsa exactamente dos botones del mando a la vez y suéltalos.
4. Activa el atajo y mantén la combinación grabada para alternar la mira.

La interfaz está organizada en pestañas. Usa **L1/R1** para cambiar de pestaña o selecciona una directamente.

## Solución de problemas
- Si una combinación funciona en el menú de Decky pero no dentro del juego, revisa el diagnóstico de botones y prueba otra combinación.
- Si desaparece la superposición de rendimiento, desactiva Crosshair para restaurar la configuración anterior de MangoHud.
- Si la mira no está centrada, ajusta X/Y o utiliza la calibración de escala.
