# 🎯 Crosshair Plugin

A customizable crosshair for Decky Loader, designed for Steam Deck, Legion Go and other handheld PCs.

**Language:** [Português](README.md) · **English** · [Español](README.es.md)

## Features
- Seven crosshair styles: Box, Dot, Ring, X, Star, Brackets and Lines.
- Preset and custom RGB colors; size from 50% to 300%.
- Screen resolution presets and fine X/Y positioning.
- Two-button controller shortcut to toggle the crosshair.
- Per-game profiles, automatically applied when a game starts.
- Restores the previous MangoHud configuration when the crosshair is disabled.

## Installation
1. Download the latest [Crosshair release](https://github.com/Havok027/crosshair-plugin/releases/latest).
2. Enable Developer Mode in Decky Loader settings.
3. Select **Install plugin from ZIP** and choose `Crosshair.zip`.
4. Restart Decky if the plugin does not appear.

## Usage
1. Open Crosshair from the Decky menu.
2. Choose the display resolution, style, color and size.
3. Enable **Show crosshair**.
4. Adjust horizontal and vertical offsets if needed.
5. Optionally save a profile for the running game.

## Controller shortcut
1. Open the **Button shortcut** section.
2. Select **Record combination**.
3. Press exactly two controller buttons together, then release them.
4. Enable the shortcut and hold the recorded combination to toggle the crosshair.

The settings interface is organized into tabs. Use **L1/R1** to move between tabs, or select a tab directly.

## Troubleshooting
- If a combination works in the Decky menu but not in-game, check the in-game button diagnostic and try another combination.
- If the performance overlay is missing, disable Crosshair to restore the previous MangoHud configuration.
- If the crosshair is off-center, adjust X/Y offsets or use scale calibration.
